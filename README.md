# CodeLook — 패션 입문자를 위한 ‘쇼핑 언어 번역’ 프로토타입

> HCI(Human Computer Interface) 개인 프로젝트 · 조희연 (223630)
> 무신사 모바일 앱의 **검색 → 필터 → 상품 상세(사이즈 결정)** 흐름 개선 기획을 Claude Code로 구현한 웹 프로토타입입니다.

- 🔗 **배포 링크:** https://heeye0n.github.io/codelook/
- 💻 **소스 코드:** https://github.com/heeye0n/codelook
- 📝 **개발 프롬프트 기록:** [PROMPTS.md](PROMPTS.md)

## 1. 프로젝트 개요

| 항목 | 내용 |
|---|---|
| 문제 | 패션 경험이 적은 대학생은 원하는 옷을 **자기 말**로는 설명할 수 있지만, 앱의 검색어·필터·상세 정보가 **패션 용어와 실측 수치**로 되어 있어 이를 앱의 언어로 바꾸지 못한다. 그 결과 검색어를 반복해서 바꾸거나 앱 밖으로 이탈하고, 맞지 않는 옷을 고른다. |
| 대상 사용자 | 패션 지식이 적고 무신사를 처음 쓰거나 가끔 쓰는 대학생 |
| 대표 과업 | 원하는 바지 1개를 골라 사이즈까지 정하기 (바지 카테고리) |
| 핵심 아이디어 | 기존 화면 위에 ‘내 말 ↔ 쇼핑 용어’를 이어 주는 **번역 장치 3가지**를 덧붙인다. 결과만 추천하지 않고 용어를 함께 보여 줘서 다음에는 스스로 검색할 수 있게 한다. |

## 2. 주요 기능 (기획서 3프레임과 대응)

| 기획 프레임 | 구현 내용 | 위치 |
|---|---|---|
| **1. 말로 찾기 + 번역 칩** | “편하고 깔끔한 바지”를 입력하면 `편하고 → 와이드` `깔끔한 → 슬랙스` 같은 번역 칩을 보여 준다. 칩은 켜고 끌 수 있고, `?`를 누르면 용어 설명을 볼 수 있다. **원래 검색어 결과도 함께 유지**한다. 같은 표현에서 나온 칩끼리는 OR, 서로 다른 표현끼리는 AND로 결과를 좁힌다. | 검색 결과 |
| **2. 그림 필터** | 핏을 **실루엣 그림 + 텍스트 라벨**로 보여 준다. 입문자 모드에서는 필터를 핏 4개·색상·가격으로 줄이고, 색상에도 쉬운 이름(예: 차콜 → 짙은 회색)을 함께 적는다. | 검색 결과 › 그림 필터, 홈 |
| **3. 용어·실측 번역** | 상품명과 실측표의 용어(세미와이드, 원턱, 총장, 밑위…)를 누르면 **그림 한 장으로 설명**한다. 키를 입력하면 **사람 실루엣 위에 바지를 겹쳐** “복숭아뼈에 닿는 길이”, “발목 위 약 6cm”처럼 몸 기준으로 보여 준다. 평소 허리 인치를 고르면 가장 가까운 사이즈를 알려 준다. | 상품 상세 |
| 쉽게 말하면 | 상품마다 통·허리·길이·소재를 쉬운 말로 요약한다. | 상품 상세 |
| 바지 용어 사전 | 용어 23개를 그림과 함께 정리하고, “이렇게 말하면 → 이렇게 찾아요” 번역표를 보여 준다. | 하단 메뉴 › 용어 사전 |
| **번역 도우미 ON/OFF** | OFF로 바꾸면 **현재 앱 방식**(글자 그대로 검색, 텍스트 필터, 설명 없는 실측표)으로 동작한다. 같은 사이트에서 개선 전후를 비교할 수 있다. | 상단 오른쪽 |
| **비교 UT 기록** | 기획서의 평가 계획을 그대로 구현했다. 참여자 ID와 조건(A 현재 방식 / B 번역 도우미)을 고르고 과업을 시작하면 **과업 시간, 검색어(순서), 재입력 횟수, 이탈 횟수(연구자 버튼), 필터·용어·칩 사용**을 자동으로 기록한다. A와 B의 평균을 목표(시간 30% 단축, 재입력+이탈 절반 이하)와 비교하고 CSV로 내보낸다. | 하단 메뉴 › UT 기록 |

### 기획서 원칙 반영 (개인 비판 검토 · 위험 대응)
- 번역이 틀릴 수 있으므로 칩은 **사용자가 해제**할 수 있고, **원래 검색 결과를 항상 함께 제공**한다.
- 용어 설명은 필요할 때만 여는 **선택형**(밑줄 친 용어와 `?` 버튼)으로 두어 과업 시간을 늘리지 않는다.
- 숙련 사용자를 방해하지 않도록 번역 도우미를 **끌 수 있다**.
- 그림 필터에는 **텍스트 라벨을 함께** 붙이고, 색만으로 정보를 구분하지 않는다.
- 키·허리 같은 신체 정보는 **선택 입력**이며 **저장하지 않는다**. UT 기록에는 개인정보를 남기지 않는다.
- 접근성: 키보드 탐색, 포커스 표시, `aria-pressed` 등 상태 안내, 본문 바로가기 링크, 다크 모드와 모션 줄이기 설정을 지원한다.

## 3. 사용 방법

1. 홈에서 예시 문장을 누르거나 검색창에 자기 말로 원하는 바지를 적는다. (예: `발목 보이는 검은 바지`)
2. 번역 칩을 확인하고, 필요하면 칩을 끄거나 `그림 필터`로 핏을 고른다.
3. 상품을 열고 밑줄 친 용어를 눌러 뜻을 확인한다. 키를 입력해 내 몸 기준 길이를 본다.
4. 사이즈를 고르고 `이 사이즈로 결정`을 누른다. (실제 결제는 없다)
5. 비교 평가를 할 때는 `UT 기록` 탭에서 조건을 골라 과업을 시작한다.

## 4. 실행 방법

빌드 과정이 없는 정적 웹사이트(HTML/CSS/JavaScript)입니다.

- **바로 실행:** `index.html`을 더블클릭해서 브라우저로 연다.
- **로컬 서버:** `python -m http.server 8000` 실행 후 `http://localhost:8000`에 접속한다.
- **배포:** GitHub Pages에서 `main` 브랜치의 루트 폴더로 설정한다.

## 6. 범위와 한계 (기획서 6절과 동일)

- 실제 검색 엔진·AI는 구현하지 않았다. 번역은 **미리 만든 용어 사전 규칙으로 시뮬레이션**한다.
- 바지 카테고리 1개, 가상 상품 18종만 다룬다. 결제·쿠폰·커뮤니티는 범위 밖이다.
- 내 몸 기준 그림은 **표준 신체 비율**(가랑이 높이 ≈ 키×0.45 등)로 계산한 참고용 근사치다.
- UT 기록은 연구자가 사용하는 기기의 브라우저에만 저장된다. (CSV로 내보내서 보관)

> 무신사 앱 개선 기획을 바탕으로 만든 학습용 컨셉 프로토타입입니다. 무신사와 관련이 없고, 상품·브랜드는 모두 가상입니다.
